# CPU Scheduling Simulator

An interactive CPU Scheduling Simulator built using HTML, CSS and JavaScript.

## 🚀 Live Demo

[▶ Open CPU Scheduling Simulator]
(https://tejaphanimanikanta3102008-source.github.io/CPU-SCHEDULING-SIMULATOR/)

## Features

- FCFS Scheduling
- SJF Scheduling
- Round Robin Scheduling
- Process input
- Gantt Chart
- Completion Time
- Turnaround Time
- Waiting Time
- Average Waiting Time
- Average Turnaround Time
