What is CPU scheduling?

CPU scheduling is the method used by an operating system to select a process from the ready queue and give it CPU time. When several processes are ready, the scheduling algorithm decides their execution order.

Goal of this simulator: Enter process arrival times and CPU burst times, choose an algorithm, and see the execution order, waiting time and turnaround time.

Key terms

Process: A program that is currently being executed.

Arrival Time (AT): The time when a process enters the ready queue.

Burst Time (BT): The CPU time required by a process.

Completion Time (CT): The time when a process finishes execution.

Turnaround Time (TAT): Total time from arrival to completion.

Waiting Time (WT): Time spent waiting in the ready queue.

Algorithms included

FCFS: First Come, First Served. Processes execute in order of arrival.

SJF: Shortest Job First. Among arrived processes, the one with the smallest burst time executes next. This version is non-preemptive.

Round Robin: Each ready process gets a fixed time quantum in turn. If it is not finished, it returns to the ready queue.

What the result means

Formulas

Turnaround Time = Completion Time − Arrival Time

Waiting Time = Turnaround Time − Burst Time

Average Waiting Time = Sum of all waiting times ÷ Number of processes

Average Turnaround Time = Sum of all turnaround times ÷ Number of processes

How each algorithm works

1. FCFS – First Come, First Served

The process that arrives first gets the CPU first. Once it starts, it runs until its CPU burst is complete. It is simple, but a long process at the front can make shorter processes wait.

2. SJF – Shortest Job First (Non-preemptive)

Whenever the CPU becomes free, the scheduler selects the arrived process with the shortest burst time. Once selected, the process runs until it finishes. If two processes have the same burst time, this simulator uses earlier arrival time, then process order.

3. Round Robin

Each ready process receives CPU time up to the time quantum. If it still has work remaining, it goes to the back of the ready queue. This gives processes turns and is commonly used to explain time-sharing systems.

Uses of CPU scheduling

  • Sharing CPU time among multiple running programs.
  • Improving responsiveness in interactive systems.
  • Managing workloads in multitasking operating systems.
  • Studying trade-offs between fairness, waiting time and throughput.
